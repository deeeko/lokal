How it works

  1. Create a request

    The agent owner runs request with a contact, an amount and a corridor. The agent adds a few cents so the amount is unique.

  2. Share the link

    The command prints a pay.html link. Send it to the payer by chat or email. It works for 48 hours unless you set another time.

  3. Payer sends the exact amount

    From their own Celo wallet: connect it and pay on the link's page, tap "Open in wallet", scan the QR code, or send it by hand to the agent's address.

  4. Autopilot pays out

    watch --execute sees the deposit, matches it to the request, converts on Textile FX and pays the contact.

Safety limits

            

              
    
                
  • Pays only a deposit that matches a request the owner created: same token, exact amount, sent after the link was made and before it expired.
    • 
                
  • Pays only contacts in contacts.json. A name on a link can't add a new recipient.
    • 
                
  • $25 per payment · $25 per person per day · $100 per day overall.
    • 
                
  • One payout per request. A second deposit for the same link is not paid.
    • 
                
  • Deposits that match no request are logged, never paid. Autopilot stops on errors.
    • 
              

            

          


          

            
What's in a link

            

              
Everything after #r= is the request itself: contact name, exact amount, corridor, note and expiry time. Nothing is stored on a server. The payment page reads the link, then checks the Celo chain for the deposit and the payout.

              
This site never holds money or keys. The payer sends from their own wallet, and the agent converts and pays the recipient.
