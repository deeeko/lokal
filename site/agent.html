Attribution tag

          ERC-8021
        

        

          

            

            
          

          
An ERC-8021 suffix is appended to the end of every transaction's calldata the agent sends. Contracts ignore the extra bytes, so the call behaves exactly as it would without them. Indexers read the suffix to attribute the transaction to this agent.

          
It is attached once, where the agent's wallet client is built (src/chain.mjs), so every transaction the agent sends carries it. After each payout the agent reads every transaction back and flags any that is missing the tag.
